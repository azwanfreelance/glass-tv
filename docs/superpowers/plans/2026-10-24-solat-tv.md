# Glass TV + Solat TV Implementation Plan

Goal: produce a phone-installable Android TV 14 APK, retaining Glass TV's original UI.
Architecture: Java launcher plus independent alarm receiver, refresh job and foreground reminder service. No TV connection or system modification. Separate stacked PRs; never merge without approval.
Tech stack: existing Java 17, SDK 34, Gradle; Android framework APIs.
Spec: user's 24 October 2026 handoff, recorded in docs/solat-tv/STATUS.md.

## Constraints
No root, debloat, ADB, Accessibility media control, force-stop, automatic PLAY command or stock launcher disabling. User selects HOME only if firmware provides its system picker. No assumption that Haier supports this.

## Review focus
Expired/malformed/foreign-zone data must never cause guessed prayers; midnight and Hijri month/year rollover; exact alarm revocation and reboot; failed media/volume operations and interruption; unsupported HOME/overlay/notification settings.
